Doopi privacy policy

Last updated: 8 October 2026

Who this covers

Doopi is a personal assistant app. It is used only by its owner on the owner's own Windows computer. This policy explains what Doopi does with Google data.

Google data Doopi can access

  • Gmail (read-only): Doopi reads the sender and subject of unread messages when the owner asks for them.
  • Google Calendar (read-only): Doopi reads upcoming events when the owner asks for them.
  • Google Docs and Sheets: Doopi reads and edits documents when the owner asks. This is added in a later update.
  • Gmail drafts: Doopi can create drafts, but never sends them without the owner's approval. This is added in a later update.

How the data is used and stored

  • Google data is used only to answer the owner's request on the owner's computer.
  • OAuth tokens are stored only on the owner's computer, in a folder that is excluded from source control.
  • Doopi does not sell Google data, use it for advertising, or share it with other people.
  • Requests are sent to the AI model used by Doopi to generate replies. Content from Google may be included in those requests when the owner asks for it.

Revoking access

You can remove Doopi's access at any time at myaccount.google.com/permissions. Deleting the stored token file on the computer also removes Doopi's local access.
